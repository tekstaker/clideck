## app.js onmessage switch (lines 120-481)
Phase 16's `case 'device.list':` and `case 'device.revoked':` arms go inside this switch. Place
them adjacent to `case 'plugins':` (around line 407 — verify by re-grepping `case 'plugins'`)
because they're thematically settings-related.

The arms:
- `case 'device.list': state.linkedDevices = msg.list; if (typeof window.__refreshLinkedDevices === 'function') window.__refreshLinkedDevices(); break;`
- `case 'device.revoked': send({ type: 'device.list.get' }); break;` — when ANY device is revoked, refresh the list (which removes the revoked row from the surviving clients' panel; also reorders if labels shifted).

The `window.__refreshLinkedDevices` callback is registered by settings.js (mirroring the
`window.__refreshStatusBadge` precedent in settings.js:141 + app.js — avoids a circular import
between app.js and settings.js).
