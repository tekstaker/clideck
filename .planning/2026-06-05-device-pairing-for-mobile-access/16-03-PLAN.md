## Public exports
- `mintOtp({ ttlSeconds = 300, isBootstrap = false } = {})` → `{ otp: '<6 upper chars>', expiresAt: '<ISO>' }`. Hard-caps ttlSeconds at 900 for user-minted; bootstrap uses 24h (caller passes ttlSeconds=24*3600).
- `redeemOtp(otp)` → `{ ok: true, isBootstrap }` on success, `{ ok: false, error: 'invalid' | 'used' | 'expired' }` on failure. Case-insensitive (callers can pass `'abc-def'` or `'ABCDEF'`).
- `bootstrapIfNeeded()` → void. If `devices.isEmpty()`, mints a bootstrap OTP, writes it to `BOOTSTRAP_PATH`, logs a styled banner to stdout. If devices already populated, no-op.
- `OTP_ALPHABET` — the 31-char string. Exported for the Wave 0 alphabet regex check.

## Alphabet pin (Q-1 resolution)
`OTP_ALPHABET = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789'` — 31 chars. SPEC said "no 0/O/1/I/l"; by my count that
excludes 5 chars from the alphanumeric 36, leaving 31. The lowercase 'l' is moot because the canonical
alphabet is uppercase-only. Wave 0 asserts this literal alphabet — DO NOT change without also editing
tests/pair-otp.test.js. Keyspace: 31^6 ≈ 887M. With single-use + 5-min TTL on a VPN-fronted endpoint,
brute-force probability is ~3.4×10⁻⁶ even at 10 req/sec sustained (RESEARCH §8 P-1).

## In-memory store shape (RESEARCH §10.3)
```
const otpStore = new Map();   // otp -> { expiresAt: <ms epoch>, used: bool, isBootstrap: bool }
```
No persistence. The store is cleared on server restart — bootstrapIfNeeded re-runs on next boot and
re-mints if devices.json is still empty. User-minted OTPs that survive their 5-min TTL across a server
restart are simply gone; user re-mints from Settings.

## Sweep (RESEARCH §10.3)
A `setInterval(..., 60_000).unref()` sweep drops expired entries so the Map can't grow unbounded.
`.unref()` is critical — without it, the interval keeps the Node process alive and the test runner
hangs after the spec finishes.

## Bootstrap banner format (RESEARCH §10.3, CONTEXT D-02)
The stdout banner is the only intentional secret-in-logs in Phase 16 (CLAUDE.md §13 calls out:
this is a deliberate, scoped exception — it's the recovery path Lance reads via SSH). Format:

  \n  [clideck] bootstrap pair code: ABC-DEF\n
       Paste into /pair on the first device.\n
       Also written to ${BOOTSTRAP_PATH}\n

The displayed `ABC-DEF` is the 6-char OTP split with a hyphen for human-friendliness. The file content
is the 6 chars WITHOUT the hyphen + a trailing newline. The /pair/redeem handler (16-04) strips all
non-alphanumeric input before lookup, so users can type either form.
